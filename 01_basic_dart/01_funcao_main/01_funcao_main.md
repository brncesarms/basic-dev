# ▶️ Dart: Função Main

> [!info] A função `main` é o ponto de partida (START) de todo programa Dart. Ela é uma função de nível superior (superior ao escopo geral do código).

---

```dart
void main() {
  // A função main é o START do programa
  print('Olá, mundo!');
}
```

> [!tip] Toda aplicação Dart precisa de uma função `main` para iniciar a execução.
