# 🪟 Flutter: Ambiente de Desenvolvimento no Windows

> [!info] Guia passo a passo para configurar o ambiente de desenvolvimento Flutter no Windows 11, utilizando Chocolatey, Java JDK, Android Studio e FVM (Flutter Version Management).

---

## 📋 Passos de Instalação

1. [Instalar o Chocolatey](./01_install_chocolatey_win.md) — Gerenciador de pacotes para Windows.
2. [Instalar o Git](./02_install_git_win.md) — Instalação e configuração de identidade do Git.
3. [Instalar o Java JDK](./03_install_java_jdk_win.md) — Java JDK 8 e 11 para compilação Android.
4. [Instalar o Android Studio](./04_install_android_studio_win.md) — IDE, SDK Manager e emuladores AVD.
5. [Instalar o FVM](./05_install_fvm_win.md) — Gerenciador de versões do Flutter por projeto.
