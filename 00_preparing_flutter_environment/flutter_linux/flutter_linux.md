# 🐧 Flutter: Ambiente de Desenvolvimento no Linux

> [!info] Guia passo a passo para configurar o ambiente de desenvolvimento Flutter em distribuições baseadas em Ubuntu/Debian, usando SDKMAN (Java), Android Studio e FVM (gerenciador de versões do Flutter).

---

## 📋 Passos

1. [Configuração do Bashrc](01_bashrc_config.md) — Variáveis de ambiente (ANDROID_HOME, FLUTTER_HOME) e aliases de JDK.
2. [Instalar o Git](02_install_git.md) — Instalação e configuração global do Git.
3. [Instalar o JDK (SDKMAN)](03_install_jdk.md) — Instalação de Java 8 e 11 via SDKMAN.
4. [Instalar o Android Studio](04_install_android_studio.md) — Instalação via snap, SDK Manager e emulador.
5. [Instalar o Flutter](05_install_flutter.md) — Instalação via snap e validação com `flutter doctor`.
6. [Instalar o FVM](06_install_fvm.md) — Gerenciamento de versões do Flutter por projeto.
