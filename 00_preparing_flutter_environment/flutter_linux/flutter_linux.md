# 🐧 Flutter: Ambiente de Desenvolvimento no Linux

> [!info] Guia passo a passo para configurar o ambiente de desenvolvimento Flutter em distribuições Linux (Debian, Ubuntu e Omarchy), utilizando SDKMAN (Java JDK), Android Studio, Flutter SDK e FVM.

---

## 📋 Passos de Instalação

1. [Configuração do Bashrc](01_bashrc_config.md) — Variáveis de ambiente (`ANDROID_HOME`, `FLUTTER_HOME`) e aliases de JDK.
2. [Instalar o Git](02_install_git.md) — Instalação e configuração de identidade do Git.
3. [Instalar o JDK via SDKMAN](03_install_jdk.md) — Instalação de Java 8 e 11 para compilação Android.
4. [Instalar o Android Studio](04_install_android_studio.md) — Instalação via snap/tarball, SDK Manager e AVD.
5. [Instalar o Flutter](05_install_flutter.md) — Instalação via snap/tarball e validação com `flutter doctor`.
6. [Instalar o FVM](06_install_fvm.md) — Gerenciamento determinístico de versões do Flutter por projeto.
